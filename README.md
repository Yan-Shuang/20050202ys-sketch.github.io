在仓库目录运行 `python3 -m http.server 8772 --bind 127.0.0.1`，然后打开 http://127.0.0.1:8772/ 。也可以直接打开 `index.html`；动效偏好保存依赖浏览器对本地存储的支持，无法保存时仍正常阅读与导航。
